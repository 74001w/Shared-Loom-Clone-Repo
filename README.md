# Shared-Loom-Clone-Repo
MarQueue (Week 1) is a web-based screen-recording platform. 
Users optionally write or paste a script, record their screen,
and receive a shareable link once the recording uploads. 
The finished recording is held in browser memory so that if an upload fails, 
the user can retry without re-recording. 
The result is a fast record-to-share loop with a 
reliability guarantee at its core.
